Developer Free Setup Guide

WebRTC allows browsers to exchange video, audio, and data directly Peer-to-Peer (P2P) without video traffic passing through a server.

The 3 Steps of WebRTC:

  1. Signaling: Browsers trade connection metadata (SDP & ICE candidates). PeerJS handles this free on their cloud server.
  2. NAT Traversal (STUN): Browsers discover their public IP addresses using free Google STUN servers.
  3. Direct P2P Stream: Once connected, audio and video stream directly between the two users with zero bandwidth server cost!
Why is it free? PeerJS provides free signaling, and Google provides free STUN. You only pay if you need TURN fallback servers for strict firewall bypasses.

Simplified minimal script to implement PeerJS in your site:

// 1. Initialize PeerJS connection
const peer = new Peer(); 

peer.on('open', (id) => {
  console.log('My Peer ID:', id);
});

// 2. Get Media Stream from webcam
const localStream = await navigator
  .mediaDevices.getUserMedia({ video: true, audio: true });

// 3. Receive Incoming Calls
peer.on('call', (call) => {
  call.answer(localStream); // Answer with camera
  call.on('stream', (remoteStream) => {
    remoteVideo.srcObject = remoteStream;
  });
});

// 4. Make an Outgoing Call
function callPeer(remoteId) {
  const call = peer.call(remoteId, localStream);
  call.on('stream', (remoteStream) => {
    remoteVideo.srcObject = remoteStream;
  });
}
